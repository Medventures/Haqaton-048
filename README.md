# Diagnostic Companion

Помощник пациента до и после МРТ, КТ, колоноскопии и маммографии.

**Команда:** 048 · DERBES / NeuroscanAI. Руслан Казыбаев, основатель NeuroscanAI и коррекционного центра DERBES.

## Проблема

Перед МРТ, КТ, эндоскопией и маммографией пациенту нужно проверить
противопоказания, сдать анализы и подготовиться. Нарушения подготовки ведут к
отменам исследований и повторным звонкам в клинику. После исследования
пациент получает заключение и не понимает его без врача, а тревожная находка
может пролежать до планового приёма.

## Решение

Один помощник проводит пациента по всей цепочке:

1. **Проверка противопоказаний и анализов.** Анкета своя для каждого
   исследования. Помощник никогда не «допускает» сам: три состояния
   «готов», «нужна проверка», «остановка до решения врача». Анализ
   креатинина (СКФ) запрашивается по факторам риска и сроку давности.
2. **Инструкция по подготовке**, собранная под ответы пациента, с отметками
   «сделано», которые видит координатор.
3. **Напоминания о визите** (за 3 дня, за сутки, за часы) с подтверждением
   или переносом. Перенос заранее вместо неявки освобождает слот.
4. **Заключение простым языком.** Каждое предложение заключения разбирается по
   словарю терминов; вверху всегда оговорка, что интерпретирует врач.
5. **Запись к специалисту при тревожных формулировках** с уровнем срочности:
   «сегодня, при ухудшении 103», «в ближайшие дни», «обсудить на приёме».

Маршруты MVP: МРТ головного мозга с контрастом, КТ органов брюшной полости с
контрастом, колоноскопия под седацией, маммография.

**Почему без генеративной модели.** Объяснение заключения и поиск тревожных
формулировок построены на словаре и правилах: ничего не выдумывается,
результат воспроизводим, данные не покидают клинику. Отрицание учитывается в
той части предложения, где стоит слово («конкрементов не выявлено»,
«без ограничения диффузии»). Для маммографии тревога определяется по
категории BI-RADS, а не по словам; для колоноскопии по Бостонской шкале
видно, что подготовка оказалась недостаточной. Открытую локальную модель
(например, через Ollama) можно подключить как дополнение к словарю, но не
вместо него.

### Метрики

| Метрика | Как считает помощник |
|---|---|
| Отмены | переносы заранее через напоминание вместо неявки |
| Нарушения подготовки | подготовка не подтверждена пациентом или недостаточна по заключению (Бостонская шкала ниже 6) |
| Повторные звонки | ответы помощника на частые вопросы; каждый считается звонком, которого не было |
| Конверсия в консультацию | записались к специалисту после тревожного заключения |

В демо метрики считаются по сессии; в клинике их сравнивают помесячно с
данными до внедрения.

## Демо

**Онлайн:** https://neuroscanai.io/static/demo/diagnostic-companion.html

**Презентация:** [docs/Diagnostic_Companion_team048.pdf](docs/Diagnostic_Companion_team048.pdf)

Локально приложение открывается одним файлом в браузере: `app/index.html`.
Пять синтетических пациентов с разными сценариями: допуск без замечаний,
просроченный креатинин при диабете и метформине, кардиостимулятор перед МРТ,
разжижающие кровь препараты перед колоноскопией, маммография с BI-RADS 4C.
Роль «Координатор клиники» показывает всех пациентов, причины остановки и
метрики.

## Запуск

Требований нет, установка не нужна. Переменные окружения и ключи не нужны.

```bash
cd app
python -m http.server 8080
```

Затем открыть http://localhost:8080. Можно открыть `app/index.html` и без
сервера, двойным щелчком.

## Структура проекта

| Путь | Назначение |
|---|---|
| `app/index.html` | интерфейс и движок: допуск, подготовка, напоминания, разбор заключения, запись, панель координатора |
| `app/routes.js` | маршруты исследований как данные: анкеты, анализы, подготовка, напоминания, частые вопросы, примеры заключений, словарь, тревожные формулировки, источники |
| `docs/Diagnostic_Companion_team048.pdf` | презентация для жюри, 8 слайдов |
| `LICENSE` | MIT |

Новый маршрут добавляется записью в `routes.js`, без изменения движка.

## Что готово

- Четыре маршрута с анкетой противопоказаний, проверкой анализа, подготовкой,
  напоминаниями и частыми вопросами.
- Разбор заключения по словарю с учётом отрицаний; уровни срочности; BI-RADS;
  Бостонская шкала.
- Запись к специалисту со свободным временем.
- Панель координатора: статусы пациентов, причины, метрики.
- Только открытый стек (требование Green Clinic): HTML, CSS, JavaScript без
  фреймворков и внешних служб.

Известные ограничения:

- Все пациенты и заключения синтетические.
- Клинические правила демонстрационные и консервативные; перед применением
  их утверждает клиника. Основа: ACR Manual on Contrast Media, консенсус
  ACR–NKF 2020 по йодсодержащему контрасту и почкам, ESUR, ESGE 2019 по
  подготовке к колоноскопии, Boston Bowel Preparation Scale, ACR BI-RADS
  Atlas 5th ed.
- Помощник не ставит диагноз и не интерпретирует снимок: он объясняет
  термины и направляет к врачу.
- Отправка WhatsApp и SMS, запись в МИС клиники и хранение на сервере в MVP
  показаны внутри интерфейса; подключение к МИС следующий шаг.
